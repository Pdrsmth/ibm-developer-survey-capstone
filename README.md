# Stack Overflow Developer Survey — Capstone Analysis

End-to-end data analyst capstone (IBM Data Analyst Professional Certificate):
data wrangling, exploratory analysis, and visualization of the
Stack Overflow Annual Developer Survey (18,845 respondents).

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Pdrsmth/ibm-developer-survey-capstone/blob/main/stackoverflow_developer_survey_analysis.ipynb)

## Key findings

- **18,845** respondents, led by the USA (3,441)
- Top language: **JavaScript** · Top database: **PostgreSQL**
- Highest median salary: **USA** (by a wide gap)
- **66%** of developers use AI tools — mostly for **writing code**
- Data quality: 0 duplicates; missing values handled per-column

## Tech

Python · pandas · matplotlib · seaborn
